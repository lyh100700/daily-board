# 말랑 캘린더

달력에서 날짜를 고르면 그 날의 일정을 바로 쓰고 고치는 개인용 캘린더입니다.
파일 하나로 돌아가고, 서버도 로그인도 필요 없습니다.

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 날짜 열기 | 달력에서 날짜 탭 → 팝업 |
| 일정 추가 | 팝업 안 `+ 일정 추가` |
| 수정 / 삭제 | 일정 카드 탭 |
| 완료 표시 | 오른쪽 동그란 체크 탭 |
| 닫기 | 바깥쪽 탭 또는 `✕` |
| 달 이동 | 오른쪽 위 `‹` `›` |

날짜 칸에는 일정 제목이 두 개까지 보이고, 더 있으면 `+2`처럼 개수가 붙습니다.

## 폰에 설치하기

**아이폰** Safari로 접속 → 공유 버튼 → `홈 화면에 추가`
**안드로이드** Chrome으로 접속 → 메뉴 → `앱 설치`

설치하면 주소창 없이 전체 화면으로 뜨고, 비행기 모드에서도 열립니다.

## 구성

```
index.html            앱 전체 (화면·기능·디자인이 이 안에 다 있음)
manifest.webmanifest  홈화면 설치 설정
sw.js                 오프라인 지원
icons/                앱 아이콘
```

## 고치고 싶을 때

- **색을 바꾸려면** `index.html` 맨 위 `:root` 블록의 색 값만 고치면 앱 전체가 바뀝니다.
- **카테고리를 바꾸려면** `<script>` 안의 `CATS` 배열을 고칩니다.
- **캐릭터를 바꾸려면** `ART` 객체의 SVG를 고칩니다. 그림 파일이 아니라 코드로 그려져 있습니다.

파일을 고쳐서 다시 올린 뒤에는 `sw.js`의 `VERSION` 숫자를 올려야 폰에 새 버전이 반영됩니다.

## 데이터

일정은 브라우저의 localStorage에 저장됩니다. **기기마다 따로 저장**되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 일정도 함께 지워집니다.

## 만든 것에 대해

캐릭터(콩이·몽이·복이·별이)는 이 저장소를 위해 직접 그린 오리지널 SVG입니다.

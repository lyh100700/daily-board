# 캘비 (CALBEE)

달력에서 날짜를 고르면 그 날의 일정을 바로 쓰고 고치는 개인용 캘린더입니다.
파일 하나로 돌아가고, 서버도 로그인도 필요 없습니다.

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 날짜 열기 | 달력에서 날짜 탭 → 팝업 |
| 일정 추가 | 팝업 안 `+ 일정 추가` |
| 수정 | 일정 카드 탭 |
| 삭제 | 오른쪽 휴지통 탭 (6초 안에 되돌리기 가능) |
| 완료 표시 | 동그란 체크 탭 |
| 닫기 | 바깥쪽 탭 또는 `✕` |
| 달 이동 | 달력을 좌우로 밀기, 또는 오른쪽 위 `‹` `›` |

날짜 칸에는 일정 제목이 두 개까지 보이고, 더 있으면 `+2`처럼 개수가 붙습니다.

## 폰에 설치하기

> 안드로이드 앱(APK)으로 설치하는 방법과 업데이트 절차는 **[ANDROID.md](ANDROID.md)** 를 보세요.

**폰 카메라로 아래 QR을 비추면** 주소를 입력하지 않고 바로 열립니다.

<img src="assets/qr.png" width="180" alt="캘비 주소 QR">

https://lyh100700.github.io/daily-board/

설치 방법은 기기마다 다릅니다. **[설치 안내 페이지](https://lyh100700.github.io/daily-board/install.html)**
에 접속하면 그 기기에 맞는 단계가 나옵니다.

- **아이폰** Safari → 공유 버튼 → `홈 화면에 추가`
- **안드로이드** Chrome → 메뉴 → `앱 설치`

> 카카오톡·네이버 앱 안에서 열린 브라우저로는 설치할 수 없습니다.
> 그 화면 메뉴에서 `다른 브라우저로 열기`를 먼저 선택하세요.

설치하면 주소창 없이 전체 화면으로 뜨고, 비행기 모드에서도 열립니다.

## 구성

```
index.html            앱 전체 (화면·기능·디자인이 이 안에 다 있음)
install.html          기기에 맞는 설치 안내
assets/qr.png         앱 주소 QR 코드
assets/splash.jpg     앱을 열 때 잠깐 보이는 첫 화면
data/knowledge.js     일반상식 콘텐츠
data/economy.js       경제상식 콘텐츠
data/words.js         영단어 콘텐츠
data/holidays.js      공휴일
fonts/                Nunito 글꼴
manifest.webmanifest  홈화면 설치 설정
sw.js                 오프라인 지원
icons/                앱 아이콘
icons/weather/        오늘 날씨 자리에 뜨는 강아지 그림
docs/                 그림 원본과 시안 (앱에는 실리지 않음)
```

## 글꼴

숫자와 알파벳은 [Nunito](https://github.com/googlefonts/nunito)를 씁니다.
끝이 둥근 글꼴이라 캐릭터의 둥근 형태와 결이 맞습니다.

한글은 기기의 시스템 글꼴을 씁니다. 한글 웹폰트는 글자 수가 많아 수 MB에 달해
앱에 심으면 첫 로딩이 크게 느려지기 때문입니다.

Nunito는 SIL Open Font License 1.1로 배포됩니다. 전문은 `fonts/Nunito-OFL.txt`에 있습니다.

## 일반상식 / 경제상식 / 영단어

달력 아래 세 장의 카드로 뜹니다. 탭하면 자세한 내용이 열립니다.

**앱을 열 때마다 새로 뽑습니다.** 나갔다 들어오면 다른 것이 보입니다.
팝업 아래 `다른 것 보기`를 누르면 그 자리에서 다른 것으로 넘어갑니다.

| 종류 | 개수 | 파일 |
|---|---|---|
| 일반상식 | 251 | `data/knowledge.js` |
| 경제상식 | 60 | `data/economy.js` |
| 영단어 | 190 | `data/words.js` |

**콘텐츠를 늘리려면** `data/` 안의 파일을 열어 배열 끝에 항목을 덧붙이면 됩니다.
앱 코드(`index.html`)는 건드릴 필요가 없습니다.

> `.json`이 아니라 `.js`로 둔 이유: 파일을 그냥 더블클릭해서 열어도 동작하게 하기 위해서입니다.
> `.json`은 웹서버 없이 열면 브라우저 보안 정책에 막힙니다.

뜻풀이와 예문은 직접 작성한 것이라 저작권 문제가 없습니다.
콘텐츠를 추가하실 때도 명언·교재 예문을 그대로 옮기지 마시고 직접 쓰시거나 속담·관용구를 쓰세요.

### 영단어는 '일상에서 쓰는 말'만

시험용 고급 어휘 대신 아침에 일어나서 잠들 때까지 실제로 입에 오르는 말만 담았습니다.
집안일·요리·장보기·병원·날씨·기분·직장처럼 **하루의 장면 순서로** 묶여 있어서,
`data/words.js`를 열면 한 상황에서 쓰는 말이 한자리에 모여 있습니다.

### 소리 내어 읽어주기

영단어 팝업의 **단어 옆**과 **예문 옆**에 있는 동그란 버튼을 누르면 원어민 발음으로 읽어 줍니다.

- 단어는 더 느리게, 예문은 말의 흐름이 살아 있을 만큼만 느리게 읽습니다.
- 읽는 중에는 버튼에 색이 차고 테두리가 숨을 쉽니다. 다시 누르면 멈춥니다.
- 폰과 컴퓨터에 이미 들어 있는 기능을 쓰기 때문에 **소리 파일을 따로 받지 않습니다.**
  기기에 저장된 목소리가 잡히면 비행기 모드에서도 나옵니다.
- 이 기능이 없는 오래된 브라우저에서는 버튼이 아예 나오지 않습니다.
  (눌러도 아무 일 없는 버튼을 남기지 않으려는 것입니다.)

> 소리가 안 나면 폰의 **무음 모드**와 **음량**을 먼저 확인하세요.
> 안드로이드는 `설정 → 접근성 → TTS 출력`에 영어 음성이 깔려 있어야 합니다.

## 공휴일

빨간 날짜로 표시되고, 달력 칸에 이름이 함께 나옵니다 (예: 현충일).

`data/holidays.js`는 두 갈래입니다.

- **고정 공휴일** — 신정·삼일절·어린이날·현충일·광복절·개천절·한글날·성탄절.
  매년 같은 날짜라 **모든 연도에서 자동으로** 표시됩니다.
- **연도별 공휴일** — 설날·추석·부처님오신날처럼 음력을 따르는 날과 대체공휴일.
  해마다 달라지므로 직접 채워야 합니다. 현재 2026년까지 들어 있습니다.

새해가 오기 전에 그 해를 추가해 두세요. **음력 날짜는 계산하지 말고 달력에서 확인**해서 넣으세요.
표에 없는 해에도 고정 공휴일은 정상적으로 나옵니다.

## 날씨

달 이름 옆 동그란 버튼을 누르면 **이번 주 날씨**가 뜹니다.
맨 위에 오늘을 크게 보여 주고, 아래로 앞으로 엿새가 한 줄씩 이어집니다.

**스크롤 없이 한 화면에 들어갑니다.** 이게 이 팝업의 규칙이라, 무언가를 키우려면
다른 데서 그만큼을 빼야 합니다. 화면이 짧은 폰에서는 자동으로 한 번 더 조입니다.

날짜 줄을 누르면 **그 날 일정으로 바로 넘어갑니다.**
'금요일에 비가 오네' 다음에 오는 생각이 '그날 약속 있었나' 라서 그렇게 이어 두었습니다.
줄 오른쪽의 작은 점이 그 날 일정입니다. 색은 달력에서 쓰는 분류 색과 같습니다.

**달력 칸에는 날씨를 넣지 않았습니다.** 일기예보는 앞으로 7일치밖에 없어서,
칸마다 얹으면 42칸 중 35칸이 영원히 비어 고장난 것처럼 보입니다.
7일은 격자보다 세로 목록에 맞는 숫자라 팝업에 목록으로 담았습니다.

### 어디서 받아오나

[Open-Meteo](https://open-meteo.com) 입니다. 인증키가 필요 없고 브라우저에서 바로
부를 수 있게 열려 있어서, 서버가 없는 이 앱에 맞습니다. 개인 사용은 무료입니다.

> 기상청 공식 API 는 인증키가 필요하고 브라우저에서 직접 부를 수 없습니다.
> 경제뉴스처럼 GitHub Actions 를 거쳐야 하는데, 날씨는 하루에도 여러 번 바뀌므로
> 하루 몇 번 커밋하는 그 방식과는 맞지 않습니다.

한 번 받아오면 **한 시간 동안은 다시 받지 않습니다.** 받아 둔 것은 기기에 저장되므로
비행기 모드에서 열어도 마지막으로 받은 예보가 그대로 보입니다.
받아온 적이 한 번도 없으면 **버튼이 아예 나오지 않습니다.**
눌러도 아무 일 없는 버튼을 남기지 않으려는 것입니다. (읽어주기 버튼과 같은 규칙)

### 사는 곳 바꾸기

**위치를 묻지 않습니다.** 개인 캘린더가 위치 권한을 물으면 사용자가 움찔하고,
얻는 것보다 잃는 것이 크다고 봐서 한 곳으로 고정했습니다.
서울이 아니라면 `index.html` 에서 이 한 줄만 고치면 됩니다.

```js
const WX_PLACE = { name: "서울", lat: 37.5665, lon: 126.9780 };
```

좌표는 지도 앱에서 그 동네를 길게 눌러 보면 나옵니다.

### 날씨 그림

두 가지를 씁니다.

**오늘 자리에는 강아지 그림**이 들어갑니다 (`icons/weather/`).
그날 날씨에 맞춰 해·구름·비·눈 넉 장 중 하나가 뜹니다.

| 그림 | 언제 |
|---|---|
| `clear.jpg` | 맑음, 대체로 맑음 |
| `cloudy.jpg` | 구름 조금, 흐림, 안개 |
| `rain.jpg` | 이슬비, 비, 소나기, 천둥번개 |
| `snow.jpg` | 눈, 싸락눈 |

넉 장으로 열여덟 가지 날씨를 덮으므로 어떤 날씨든 빈자리가 생기지 않습니다.
그림을 더 만드시면 `index.html` 의 `wxPhoto()` 함수에 줄만 더하면 됩니다.
원본과 만드는 방법은 [docs/](docs/) 에 있습니다.

**목록과 아침·낮·저녁·밤에는 코드로 그린 아이콘**을 씁니다 (`WX_ART`).
맑음·구름조금·흐림·안개·비·눈·천둥번개 일곱 가지입니다.
여기에 강아지 그림을 넣지 않은 이유는, 26px 로 줄면 강아지가 흰 덩어리로
뭉개져서 무슨 날씨인지 알아볼 수 없기 때문입니다.

세계기상기구 코드는 백 가지 가까이 되지만, 작은 아이콘으로 구분되는 것은 이 정도가 한계입니다.
아이콘의 얼굴은 큰 그림에만 넣었습니다. 작은 그림에 넣으면 역시 뭉개집니다.

## 고치고 싶을 때

- **색을 바꾸려면** `index.html` 맨 위 `:root` 블록의 색 값만 고치면 앱 전체가 바뀝니다.
- **카테고리를 바꾸려면** `<script>` 안의 `CATS` 배열을 고칩니다.
- **캐릭터를 바꾸려면** `ART` 객체의 SVG를 고칩니다. 그림 파일이 아니라 코드로 그려져 있습니다.
- **사는 곳을 바꾸려면** `WX_PLACE` 의 좌표를 고칩니다. 날씨가 그 동네 것으로 바뀝니다.

파일을 고쳐서 다시 올린 뒤에는 `sw.js`의 `VERSION` 숫자를 올리세요.
숫자가 바뀌어야 폰이 "새 버전이 나왔다"는 것을 알아챕니다.

앱은 켤 때마다 새 버전이 있는지 스스로 확인하고 조용히 갈아끼웁니다.
사용자가 새로고침할 필요는 없습니다. 다만 일정을 입력하는 창이 열려 있으면
내용이 날아가지 않도록 창을 닫은 뒤에 적용합니다.

## 데이터

일정은 브라우저의 localStorage에 저장됩니다. **기기마다 따로 저장**되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 일정도 함께 지워집니다.

## 만든 것에 대해

일정 분류에 쓰이는 캐릭터(콩이·몽이·복이·별이)는 이 저장소를 위해 그린 오리지널 SVG입니다.
앱 아이콘과 첫 화면의 다람쥐 그림은 별도로 제작해 넣은 이미지입니다.

# 캘비 (CALBEE)

달력에서 날짜를 고르면 그 날의 일정을 바로 쓰고 고치는 개인용 캘린더입니다.
파일 하나로 돌아가고, 서버도 로그인도 필요 없습니다.

## 쓰는 법

| 동작 | 방법 |
|---|---|
| 날짜 열기 | 달력에서 날짜 탭 → 팝업 |
| 일정 추가 | 팝업 안 `+ 일정 추가` |
| 수정 | 일정 카드 탭 |
| 삭제 | 오른쪽 휴지통 탭 (6초 안에 되돌리기 가능) |
| 완료 표시 | 동그란 체크 탭 |
| 닫기 | 바깥쪽 탭 또는 `✕` |
| 달 이동 | 오른쪽 위 `‹` `›` |

날짜 칸에는 일정 제목이 두 개까지 보이고, 더 있으면 `+2`처럼 개수가 붙습니다.

## 폰에 설치하기

**아이폰** Safari로 접속 → 공유 버튼 → `홈 화면에 추가`
**안드로이드** Chrome으로 접속 → 메뉴 → `앱 설치`

설치하면 주소창 없이 전체 화면으로 뜨고, 비행기 모드에서도 열립니다.

## 구성

```
index.html            앱 전체 (화면·기능·디자인이 이 안에 다 있음)
assets/splash.jpg     앱을 열 때 잠깐 보이는 첫 화면
data/knowledge.js     오늘의 상식 콘텐츠
data/words.js         오늘의 단어 콘텐츠
data/holidays.js      공휴일
fonts/                Nunito 글꼴
manifest.webmanifest  홈화면 설치 설정
sw.js                 오프라인 지원
icons/                앱 아이콘
```

## 글꼴

숫자와 알파벳은 [Nunito](https://github.com/googlefonts/nunito)를 씁니다.
끝이 둥근 글꼴이라 캐릭터의 둥근 형태와 결이 맞습니다.

한글은 기기의 시스템 글꼴을 씁니다. 한글 웹폰트는 글자 수가 많아 수 MB에 달해
앱에 심으면 첫 로딩이 크게 느려지기 때문입니다.

Nunito는 SIL Open Font License 1.1로 배포됩니다. 전문은 `fonts/Nunito-OFL.txt`에 있습니다.

## 오늘의 상식 / 오늘의 단어

달력 아래 두 장의 카드로 뜹니다. 탭하면 자세한 내용이 열립니다.

날짜에 따라 순서대로 넘어가므로 **새로고침해도 그날 것은 바뀌지 않습니다.**
현재 상식 202개, 단어 212개가 들어 있습니다.
팝업 아래 `다른 것 보기`로 무작위로 넘겨볼 수도 있습니다.

**콘텐츠를 늘리려면** `data/` 안의 파일을 열어 배열 끝에 항목을 덧붙이면 됩니다.
앱 코드(`index.html`)는 건드릴 필요가 없습니다.

> `.json`이 아니라 `.js`로 둔 이유: 파일을 그냥 더블클릭해서 열어도 동작하게 하기 위해서입니다.
> `.json`은 웹서버 없이 열면 브라우저 보안 정책에 막힙니다.

뜻풀이와 예문은 직접 작성한 것이라 저작권 문제가 없습니다.
콘텐츠를 추가하실 때도 명언·교재 예문을 그대로 옮기지 마시고 직접 쓰시거나 속담·관용구를 쓰세요.

## 공휴일

빨간 날짜로 표시되고, 달력 칸에 이름이 함께 나옵니다 (예: 현충일).

`data/holidays.js`는 두 갈래입니다.

- **고정 공휴일** — 신정·삼일절·어린이날·현충일·광복절·개천절·한글날·성탄절.
  매년 같은 날짜라 **모든 연도에서 자동으로** 표시됩니다.
- **연도별 공휴일** — 설날·추석·부처님오신날처럼 음력을 따르는 날과 대체공휴일.
  해마다 달라지므로 직접 채워야 합니다. 현재 2026년까지 들어 있습니다.

새해가 오기 전에 그 해를 추가해 두세요. **음력 날짜는 계산하지 말고 달력에서 확인**해서 넣으세요.
표에 없는 해에도 고정 공휴일은 정상적으로 나옵니다.

## 고치고 싶을 때

- **색을 바꾸려면** `index.html` 맨 위 `:root` 블록의 색 값만 고치면 앱 전체가 바뀝니다.
- **카테고리를 바꾸려면** `<script>` 안의 `CATS` 배열을 고칩니다.
- **캐릭터를 바꾸려면** `ART` 객체의 SVG를 고칩니다. 그림 파일이 아니라 코드로 그려져 있습니다.

파일을 고쳐서 다시 올린 뒤에는 `sw.js`의 `VERSION` 숫자를 올리세요.
숫자가 바뀌어야 폰이 "새 버전이 나왔다"는 것을 알아챕니다.

앱은 켤 때마다 새 버전이 있는지 스스로 확인하고 조용히 갈아끼웁니다.
사용자가 새로고침할 필요는 없습니다. 다만 일정을 입력하는 창이 열려 있으면
내용이 날아가지 않도록 창을 닫은 뒤에 적용합니다.

## 데이터

일정은 브라우저의 localStorage에 저장됩니다. **기기마다 따로 저장**되며 서버로 전송되지 않습니다.
브라우저 데이터를 지우면 일정도 함께 지워집니다.

## 만든 것에 대해

일정 분류에 쓰이는 캐릭터(콩이·몽이·복이·별이)는 이 저장소를 위해 그린 오리지널 SVG입니다.
앱 아이콘과 첫 화면의 다람쥐 그림은 별도로 제작해 넣은 이미지입니다.
